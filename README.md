# Experimental School Choice with Parents — Replication Package

Stata replication code for **every table environment** in *Experimental School Choice with Parents* by Mikhail Freer, Thilo Klein, and Josué Ortega.

The package generates 27 LaTeX table files in manuscript order, reconstructs all participant-level measures from the restricted 540-person analysis file, estimates all eight cognitive models, and stops if any validation target fails.

This public repository distributes **code and aggregate/design inputs only**. Participant-level behavioral, demographic, ranking, and Raven-response data are not public. Authorized users must place `analysis_input.csv` in `data/`; see [`data/README.md`](data/README.md).

## Run

Requirements: **Stata 18 or later**. No community-contributed Stata packages are required.

```stata
cd "PATH/TO/Replication_Parents"
do 00_master.do
```

Without the restricted participant file, the master script exits with an explicit setup message. Static/design tables and published aggregate-output tables can still be generated by running `code/04_published_simulation_tables.do` and `code/05_design_tables.do` after defining the root globals used in `00_master.do`.

Successful completion prints:

```text
Replication completed: all 27 manuscript tables generated and validated.
```

Outputs are written to:

- `output/tables/`: 27 manuscript-ordered LaTeX tables;
- `output/data/analysis_sample.dta`: constructed analysis data;
- `output/data/skipping_definition_diagnostic.csv`: published-code and strict-prose definitions side by side;
- `output/logs/replication.log`: complete run and validation log.

## What is reproduced from what

| Evidence layer | Tables | Treatment |
|---|---|---|
| Deidentified participant records | 7, 9–13, 17, 24–25, 27 | Measures and estimates are reconstructed in Stata. Table 8 also uses two external benchmark series. The RM cells in Tables 12–13 use the archived published tie-breaking summary. |
| Fixed experimental design / manuscript constants | 1–6, 18–23 | Stata generates the tables from included design inputs and algorithm illustrations. |
| Published recombinant-estimator output | 14–16, 26 | Stata regenerates the tables from the included published estimates. The underlying recombinant draw file and `recombinant_estimator_v2.R` were not present in the supplied author folder. |

This distinction is deliberate. The package never describes a copied manuscript cell as a newly re-simulated estimate. See [REPLICATION_NOTES.md](REPLICATION_NOTES.md) for the exact provenance and all source/manuscript discrepancies.

## Validation

`code/06_validation.do` checks:

- all 62 reported regression coefficient/standard-error cells;
- treatment sample sizes, market sizes, and all direct table numerators;
- demographic totals, truth-telling, quiz, obvious-mistake, first-deviation, and manipulation-pattern cells;
- fixed preferences and priorities as complete permutations;
- every published recombinant/RM snapshot row; and
- existence of all 27 output files.

The independent paper-to-file crosswalk is in [TABLES.md](TABLES.md) and the machine-readable version is `verification/table_manifest.csv`.

## Restricted data

The participant file used during construction was stripped of names, email addresses, original participant/session codes, recruitment identifiers, payment identifiers, free-text responses, and platform credentials. Participant and market IDs are arbitrary sequential values. It nevertheless contains individual behavioral, demographic, ranking, and cognitive-response records, so it is intentionally excluded from this public repository. Its expected SHA-256 checksum is supplied for authorized users.

## Important CDE scaling detail

The appendix Raven measure that reproduces the reported coefficients is

```text
(correct C + correct D + correct E) / 3
```

not the raw 36-item sum. Treatment sDA is excluded from that specification because blocks D and E are incomplete.
